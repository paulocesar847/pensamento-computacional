Anotações sobre a aula: Intermediário!

  • commit significa a versão do site;
  • master é o mesmo que main;
  • devemos programar no developer e não no main, para precaução de corromper;
  • branch é a linha do tempo de todas as versões do site;
  • diretório é uma pasta, e, repositório é quando o git começa a trabalhar dentro dela;
